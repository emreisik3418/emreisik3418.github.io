Privacy Policy — Umay Wonders Uploader

Last updated: 23 November 2026

What this app is

Umay Wonders Uploader is a private automation tool used only by the owner of the YouTube channel Umay Wonders. It prepares educational videos and uploads them to that channel as private videos for the owner to review. It is not offered to the public, and no one other than the channel owner signs in to it.

Data the app accesses

  • YouTube: uploads videos and captions to the owner's own channel, and reads that channel's own statistics (YouTube Data API and YouTube Analytics API).
  • Google Drive and Google Sheets: reads the channel's topic calendar and notes, and saves scripts, review reports and video files to the owner's own Drive folders.

The app does not access data belonging to any other Google user, and it does not collect any information from viewers of the channel, including children.

How data is used and stored

Data is used only to produce and publish the channel's videos and to review their performance. Access credentials are stored as encrypted secrets in the owner's private GitHub repository. Data is not sold, shared with third parties, or used for advertising.

Video scripts are generated with the Anthropic Claude API and narration with Google Cloud Text-to-Speech. Only the episode topic and script text are sent to these services; no personal data is sent.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The owner can revoke the app's access at any time at myaccount.google.com/permissions.
